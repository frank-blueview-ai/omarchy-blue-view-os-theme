# Blue View OS theme for Omarchy

A dark navy Omarchy theme with a bright blue accent, blue-to-gold window borders, and Blue View wallpapers for day, golden hour, and night.

## Install

```bash
omarchy theme install https://github.com/frank-blueview-ai/omarchy-blue-view-os-theme.git
```

The installer replaces any existing theme directory named `blue-view-os`; back up a local theme with that name before installing. The theme sets `Yaru-blue-dark` as its icon theme; install that icon theme separately if needed.

This repository contains the theme's appearance files and wallpapers. Separate Blue View plugins, custom keybindings, window rules, and application behavior are not included.
